# Proposal

## Why

O estudante precisa relacionar seus registros de estudo a uma meta mensurável da disciplina e decidir o próximo passo com evidências.

## What Changes

- Uma meta editável por disciplina com indicador, valor e prazo.
- Progresso, ritmo, tendências e alertas calculados com dados próprios dos módulos habilitados.
- Painel no detalhe com evidências, sugestões e atalhos; funcionamento independente da IA.

## Capabilities

### New Capabilities
- `subject-goal-insights`: metas mensuráveis e orientações verificáveis por disciplina.

### Modified Capabilities
Nenhuma.

## Impact

Contratos, migration MySQL, interfaces públicas dos módulos produtores, API de disciplinas e painel React com testes.
